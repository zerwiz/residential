# MAISON | Exceptional Properties

A curated digital portfolio showcasing the world's most extraordinary residences. Where architecture meets artistry.

![MAISON Logo](https://z-cdn.chatglm.cn/z-ai/static/logo.svg)

## 🏛️ About

MAISON is an exclusive digital platform presenting an elite collection of exceptional properties around the globe. From Malibu's glass pavilions to Malibu's glass pavilions to Parisian penthouses, each property is carefully selected for its architectural brilliance, artistic significance, and unparalleled luxury.

## ✨ Features

- **Elegant Design** - Sophisticated typography with Playfair Display and Inter fonts
- **Parallax Scrolling** - Smooth, immersive animations with Framer Motion
- **Responsive Layout** - Fully optimized for all device sizes
- **Custom Animations** - Hairline borders, gold accents, and fluid transitions
- **Interactive Navigation** - Sticky header with smooth scroll behavior

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Google Fonts (Playfair Display, Inter)

## 📦 Installation

```bash
npm install
# or
yarn install
```

## 🚀 Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## 📱 Deployment

```bash
npm run build
npm start
```
